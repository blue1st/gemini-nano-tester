このブラウザでは Chrome Built-in AI (Prompt API) が有効化されていないか、サポートされていません。以下の手順を実行してください。

1

フラグの設定（コピーしてURLバーに貼付）

chrome://flags/#prompt-api-for-gemini-nano

→ Enabled または Enabled with bypass に変更

2

デバイスモデルの設定

chrome://flags/#optimization-guide-on-device-model

→ Enabled BypassPerfRequirement または Enabled に変更

3

ブラウザを再起動

設定変更後、Chromeを完全に再起動します。

🔍 フラグを設定しても起動しない場合のチェックリスト

  • ■
    Mac の SSD 空き容量（22GB 以上必要）:

    オンデバイスAIは、ストレージ容量が少ないとChromeがダウンロードを静かに制限し、APIを無効化（`undefined`）します。不要なファイルを整理して容量を確保してください。

  • ■
    chrome://on-device-internals でのDL状態確認:

    新しいタブで chrome://on-device-internals を開き、「Model Status」 タブを確認してください。モデルのロード進捗やDL完了状況、発生しているエラーなどのリアルタイム診断が行えます。

  • ■
    Mac上での Chrome の完全終了（Cmd + Q）:

    「Relaunch」ボタンだけでは裏プロセスが残ることがあります。Cmd + Q でChromeを完全に終了させてから再起動してください。

ℹ️ Nano仕様
Aether Local AI はブラウザの Gemini Nano モデルを使用してローカルで推論を行います。データが外部サーバーに送信されることはありません。

🧠 Gemini Nano (Prompt API) の仕様

Chrome built-in Prompt API は、Google Chrome がローカルデバイス上で実行するオンデバイスAI機能です。

  • モデル名: Gemini Nano
  • パラメータ数: 約1.8B / 3.2B (デバイス性能に依存)
  • コンテキスト窓: 通常 4,096 トークン
  • 動作特性: 完全に100%ローカル（機密情報の処理、完全オフライン対応）

Thinking Mode: 本クライアントのThinking Modeは、Chain-of-Thought (思考プロセス) を擬似的に誘発するプロンプト制御と、出力ストリームのリアルタイムパーシングを組み合わせ、高度な論理推論プロセスと推論速度(Tokens/sec)を可視化するプレミアム機能です。
